### How I work with AI

I use Claude Code, Cursor and GitHub Copilot daily — but as tools that still need a competent operator. In practice that means writing precise prompts, comparing outputs across models before committing to one, putting generated code through the same review as anything else, and documenting it (PHPDoc, README) so it stays maintainable. Speed is only worth it when the result holds up six months later.
